## 3. Notes

- All estimators are implemented from scratch on a single NumPy CART decision tree; the only hard dependency is `numpy`.
- scikit-learn is used solely for datasets and baseline comparisons; it is an optional extra (`pip install -e .[demo]`).
- Tree depth, learning rate, number of estimators and split fractions are deliberately modest to keep the demo fast and deterministic.
- RandomForest and ExtraTrees report Mean Decrease Impurity (`feature_importances_`) for the classification features.
